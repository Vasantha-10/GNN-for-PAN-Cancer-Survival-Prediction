# GNN for PAN-Cancer Survival Prediction

## Overview

This project presents a Graph Neural Network (GNN) framework enhanced with Squirrel Search and Deer Hunting (SSDH) optimization strategies for PAN-Cancer Survival Prediction. The model analyzes gene expression and clinical data to predict patient survival outcomes across multiple cancer types.

## Problem Statement

Cancer survival prediction is challenging due to the complexity and diversity of cancer types. Traditional machine learning models often struggle with high-dimensional biomedical datasets and complex biological relationships.

This project addresses these challenges by combining Graph Neural Networks with nature-inspired optimization techniques to improve feature selection and prediction accuracy.

## Objectives

* Predict survival outcomes across multiple cancer types.
* Analyze high-dimensional gene expression data.
* Improve feature selection using SSDH optimization.
* Capture biological relationships using Graph Neural Networks.
* Enhance prediction accuracy and model interpretability.

## Dataset

The model utilizes PAN-Cancer datasets obtained from:

* The Cancer Genome Atlas (TCGA)

The dataset contains gene expression and clinical information collected from multiple cancer types.

## Methodology

### Data Preprocessing

* Data Cleaning
* Normalization
* Log Transformation
* Dimensionality Reduction

### Feature Selection

The SSDH algorithm is used to identify biologically significant genes that contribute to survival prediction.

### Graph Construction

Patient samples are transformed into graph structures based on gene expression similarities.

### Model Development

A Graph Neural Network is trained to learn relationships between patient samples and predict survival outcomes.
